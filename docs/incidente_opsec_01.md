# Incidente OPSEC 01 — Blob raster em assets/svg_base/jehanne.svg

- **Data:** 2026-08-28
- **Descrição:** SVG de trabalho com imagem de referência embutida (base64) foi versionado no commit cc04936 enquanto o repositório estava público.
- **Contenção:** Repositório tornado privado imediatamente, depois deletado.
- **Correção:** Repositório deletado e reconstruído com histórico novo; arquivo de trabalho mantido apenas localmente, sob .gitignore.
- **Regra permanente:** Nenhum SVG é commitado sem o checklist de raster; svg_base/ e rasters jamais são versionados.
